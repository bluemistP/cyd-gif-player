✂️ Edit before uploading

Keep 1 out of every N frames — fewer frames means faster decoding on the device. Dropped frames' time is added to the frame kept, so the loop still takes the same total time.
Fewer colors means a smaller file and slightly less decode work on the CYD — flat-shaded art (like most anime) usually looks fine even at "Minimal". Shown live in the preview above.
Note: this doesn't re-encode with per-frame delta/bounding-box compression (like gifsicle -O3) — that would need a much bigger custom encoder. The wins here come from fewer frames, a smaller crop, and fewer colors.
